# 후속 기능 사용 안내

## 고정 미리보기

https://subpidea-preview-tiredestests-projects.vercel.app

Supabase Site URL과 `/auth/callback` 허용 목록에 이 주소를 설정합니다. 사용자가 설정 완료를 확인했습니다. 이후 재배포는 `scripts/deploy-preview.ps1`을 실행하면 성공한 Preview에 고정 주소를 다시 연결합니다. 배포가 실패하면 기존 연결을 유지합니다. 유료 도메인을 구매하지 않으며 기존 배포 보호 설정을 유지합니다.

## 마이페이지와 팔로우

- 로그인 후 헤더의 마이페이지에서 내 평가·한줄평·관심 게임을 확인합니다.
- 활동은 20개씩 표시되며, 비공개 대상이나 제외된 등장 관계의 평가·한줄평은 공개 목록에 노출하지 않습니다. 원본 기록은 보존됩니다.
- 닉네임은 2~24자로 저장합니다. 기존 한줄평에서도 바뀐 이름이 표시됩니다. 닉네임은 중복을 허용하며 관리자 권한이나 Google 계정 정보와는 별개입니다.
- 게임 상세 화면에서 팔로우·해제할 수 있습니다. 팔로우 목록은 본인만 볼 수 있고 알림 발송 기능은 포함하지 않습니다.
- 관리자 계정의 마이페이지에는 관리자 화면 링크가 표시됩니다.

## 등장 캐릭터

관리자 → 등장 캐릭터에서 게임과 장을 선택합니다.

- 추가: 해당 게임의 캐릭터와 표시 순서를 선택합니다.
- 순서 저장: 기존 연결의 순서를 변경합니다.
- 제외: 연결을 비활성화하여 공개 등장 목록과 해당 캐릭터의 장별 평가를 숨깁니다. 평가는 삭제되지 않습니다.
- 복원: 제외된 연결과 기존 평가·한줄평을 다시 표시합니다. 부모 콘텐츠와 캐릭터도 공개 상태여야 합니다.
- 교체: 기존 연결을 제외하고 새 캐릭터 연결을 추가합니다. 평가·한줄평은 새 캐릭터로 이동하지 않습니다. 이미 등록된 캐릭터라면 기존 연결의 복원을 이용합니다.

변경은 하나의 DB 트랜잭션으로 처리하고 변경 기록을 남깁니다. 수정 시각이 달라졌으면 새로고침하도록 차단합니다. Excel의 누락 행은 여전히 자동 삭제하지 않으며, 제외된 연결을 재반입해도 자동 복원하지 않습니다.

## 게임 헤더를 Excel에 포함

1. 관리자 → 게임 헤더에서 기존 게임을 선택하고 JPEG·PNG·WebP 파일을 업로드합니다. 파일은 3MB 이하, 2천만 픽셀 이하의 정지 이미지여야 합니다.
2. 원본 비율을 유지하면서 최대 1600×900 범위의 WebP로 변환합니다. 작은 이미지는 확대하지 않고 EXIF 메타데이터를 제거합니다. 원본 파일은 사용자가 보관합니다.
3. 화면에 나온 경로를 Excel의 `GAMES` 시트에 넣습니다. 1행은 `source_id`, `hero_image`, `cover_image`이고 2행은 현재 게임 ID와 이미지 경로입니다. 블루 아카이브의 ID는 `BA`입니다.
4. 헤더만 바꿀 때 `hero_image`에 경로를 넣고 `cover_image`는 비웁니다. 빈 칸이나 GAMES 시트가 없는 기존 파일은 현재 이미지를 유지합니다.
5. Excel 가져오기에서 파일 검사 → 경로 변경 확인 → 일괄 적용합니다. 등록된 이미지인지도 검사합니다.

업로드만으로 헤더가 바뀌지 않습니다. 연결 전 이미지는 일반 사용자에게 공개되지 않습니다. 게임을 처음 추가할 때는 게임을 먼저 등록한 뒤 헤더를 업로드합니다. Excel 내부에 삽입된 그림 추출은 지원하지 않으며, 파일 경로와 이미지 업로드를 연결하는 방식입니다.

## 검증 기록

- Node 테스트 10개: 기존/선택 GAMES 시트, 이미지 경로 제한, 등장 순서, 잘못된 Excel, 닉네임 입력, 이미지 변환·잘못된 파일 거절
- DB 트랜잭션 테스트: 본인 팔로우만 조회/수정, 비공개 게임 신규 팔로우 차단, 닉네임 소유권, 일반 사용자 관리자 RPC/업로드 차단, 등장 교체·복원·평가 보존·변경 이력·경합 차단
- 기존 RLS, 관리자 일괄 반영, 별점 취소 회귀 검증 통과
- 타입 검사와 Webpack 프로덕션 빌드 통과
- 보안 진단에서 이번 스키마 관련 경고 없음. 기존 유출 비밀번호 보호 미설정 경고는 Google OAuth와 별개의 항목으로 남아 있음

로그인한 실제 운영자 계정으로 UI 저장 흐름을 최종 확인해야 합니다. DB 테스트의 임시 계정·평가·업로드 메타데이터는 모두 rollback하여 실제 데이터에 남기지 않았습니다.
