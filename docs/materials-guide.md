| 폴더 | 넣을 자료 |
|---|---|
| excel | 원본 Excel 파일 |
| images/characters | 캐릭터 이미지 |
| images/stories | 게임·편·장 대표 이미지. 기존 하위 폴더 유지 가능 |
| ui-references | UI 참고 스크린샷, 참고 URL·설명 메모 |

기존 파일명과 하위 폴더 구조를 유지해서 복사한다. 이미지 이름이나 Excel 컬럼을 미리 수정할 필요는 없다. 캐릭터·스토리 이미지가 섞여 있으면 images 아래에 기존 폴더를 통째로 복사해도 된다. 여러 Excel 버전이 있다면 사용할 최신본을 알려준다.

이 폴더는 .gitignore 대상이므로 원본 자료를 Git에 자동 포함하지 않는다. 추후 사용할 이미지는 분석 후 Supabase Storage로 업로드한다. 이 로컬 폴더 자체는 클라우드 백업이나 공유 폴더가 아니다.

## UI 레퍼런스 전달

다음 중 편한 방법을 사용한다.

- 이 대화에 스크린샷 첨부.
- ui-references 폴더에 이미지 저장.
- 참고 사이트 URL과 참고할 부분을 대화 또는 텍스트 파일에 작성.

전체 화면과 좋아하는 부분을 함께 알려주면 좋다. 예: ‘이 화면의 카드 배열’, ‘이 사이트의 별점 표시’, ‘장 상세는 의뢰서처럼 2열’, ‘색상은 밝은 톤’.

2~3개 정도면 출발하기 충분하다. 별도 Figma 파일이나 디자인 문서를 새로 만들 필요는 없다. 참고 화면이 없어도 원하는 밝기·색감·분위기와 의뢰서를 바탕으로 첫 시안을 만들 수 있다.
