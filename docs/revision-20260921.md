# 2026-09-21 수정사항 반영

사용자가 제공한 수정사항 PDF 5페이지를 기준으로 합니다.

## 이번 반영

- 사이트 제목·푸터: 게임 스토리, 캐릭터 평가 및 공유 서비스
- 홈 문구: 게임 스토리와 캐릭터, 평가하고 공유하세요. (PDF의 대체 문구가 비어 있어 간결한 문구로 작성)
- 게임 목록 제목: 게임 탐색
- 별의 좌우 반쪽을 눌러 0.5점 단위 즉시 저장. 동일 점수 재선택 시 평가 취소. 키보드 Tab/Enter로도 조작 가능
- 평가한 대상에만 한줄평 작성·수정 허용. DB 트리거에서도 검증
- 한줄평에 작성자의 해당 대상 현재 별점 표시. 사용자 확인에 따라 별점 취소 후 한줄평은 보존하고 표시 별점만 제거. 기존 한줄평 삭제는 별점 없이도 가능
- Excel 빈 예약 행의 고정 행 번호 의존 제거. 실수로 일부 값만 입력한 행은 오류 유지. 기존 등장 순서 변경 반영

## 등장 캐릭터를 추가·수정하는 방법

1. `CHARACTERS`에 대상 캐릭터의 고유 ID·이름·작업 순번이 있는지 확인합니다.
2. `Appearances`에 장의 `story_id`와 캐릭터의 `No`를 입력합니다. `character_id`와 `name` 수식 결과가 해당 캐릭터와 일치해야 합니다. 수식이 없다면 마스터와 동일하게 직접 입력합니다.
3. `display_order`에 0 이상의 정수를 넣으면 그 순서로 반영됩니다. 비워 두면 장 내 Excel 행 순서로 계산됩니다.
4. Excel에서 수식을 다시 계산하고 저장한 뒤 관리자 → Excel 가져오기 → 파일 검사로 변경 목록을 확인합니다. 검사는 저장이 아닙니다. 확인 체크 후 일괄 적용해야 사이트에 반영됩니다.
5. 새 캐릭터는 비공개로 들어오므로 관리자 콘텐츠 편집에서 공개 여부와 이미지를 설정합니다. 장·편·게임 역시 공개되어야 노출됩니다.

현재 로컬 Excel은 712개 등장 관계이며, 기존 반입 703건에서 변경됐습니다. PDF 오류에 나온 258·260·262행은 장 ID만 있고 캐릭터 값이 없는 빈 예약 행입니다. 보완 후 오류 없이 판독됩니다. 이번 코드 수정만으로 Excel 변경을 자동 적용하지 않습니다. 관리자에서 변경 목록을 검토해 적용합니다.

누락 행은 자동 삭제하지 않습니다. 기존 등장 캐릭터의 교체를 위해 Excel 행의 ID를 바꾸면 새 연결이 추가되고 이전 연결은 보존됩니다. 연결 삭제·교체 전용 UI는 별도 후속 범위입니다.
